# check_my_email

Library for Check my Email


## Install from PYPI

The homepage in pipy is https://pypi.org/project/check_my_email/

```bash
pip install --upgrade check_my_email
```

## Install from source
Installing `check_my_email` library

```bash
git clone https://github.com/trucomanx/CheckMyEmail.git
cd CheckMyEmail
pip install -r requirements.txt
cd src
python -m build
pip install dist/check_my_email-*.tar.gz
```

## Uninstall

```bash
pip uninstall check_my_email
```
